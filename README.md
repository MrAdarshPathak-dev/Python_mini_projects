# Python Mini Projects

A collection of small Python projects built to practise programming fundamentals and develop practical skills. Each project lives in its own folder and has its own instructions.

## Projects

| Project | Description | Status |
| --- | --- | --- |
| [Student Result Manager](./student_result_manager/README.md) | Add students, view marks, and check pass/fail results from a command-line menu. | Available |
| `calculator/` | A command-line calculator project. | Planned |
| `todo-cli/` | A command-line to-do list project. | Planned |
| `library-management/` | A library management project. | Planned |
| `quiz-game/` | A command-line quiz game. | Planned |

## Getting started

Each project may have different requirements. Open its folder and follow the instructions in that project's README. For example, to run the Student Result Manager:

```bash
cd student_result_manager
python app.py
```
